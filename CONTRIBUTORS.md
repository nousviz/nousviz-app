# Contributors

NousViz was developed privately through the v0.x line before this
repository's initial v1.0 commit, which squashed that history into a
single commit — flattening everyone's authorship with it. This file
records the people behind the project.

- **John Wright** ([@statsdroneadmin](https://github.com/statsdroneadmin)) —
  creator and maintainer: built NousViz from scratch, including the
  platform, backend, frontend, plugin system and releases; product
  direction, testing and operations.
- **Joe Hatch** ([@JoeHatch](https://github.com/JoeHatch)) — contributor:
  development across the v0.x–v1.0 line.
- **Darrell Helyar** ([@darrell-helyar](https://github.com/darrell-helyar)) —
  development and product feedback across the v0.x–v1.0 line, including
  admin UI work.
